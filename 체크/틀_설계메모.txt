========================================
와카데미 틀.HTML 설계 메모
========================================
목적: 틀.HTML + 치환값 매핑 → py 구동으로 1.9만 페이지 일괄 생성

----------------------------------------
페이지 순서 (최종)
----------------------------------------
1. HEADER          (고정)
2. HERO            (유동: {{지역키워드}}, {{메인키워드}})
3. PAIN            (유동 일부: fact box에 {{지역키워드}} {{메인키워드}})
4. PROMISE         (유동: {{메인키워드}})
5. SECTION 1~8     (유동: JSON result.html 전체)
6. REVIEWS         (유동: 리뷰txt 6개)
7. BOTTOM CTA      (고정)

----------------------------------------
고정값 (모든 페이지 동일)
----------------------------------------
- Header 로고: 와카데미
- Hero top label: 와카데미 학원 정보 안내
- Hero sub: 공공데이터(NEIS) 기반 학원 정보를 안내합니다.
- Hero badges: {{지역키워드}} / 수강료 공개 / 커리큘럼 확인  (3개)
- Promise 3항목:
    일대일 지도   ──  관리가 잘 되는
    맞춤형 진도   ──  이해가 될 때까지
    공부법 관리   ──  배움 이후 적용
- Pain 모노로그 3개 (고정):
    1. 진도가 빨라서 / 못 따라가요...
    2. 방법을 몰라서 / 학원 가도 안늘어요...
    3. 공부 의지가 없어서 / 걱정이에요...
- Reviews H2: 수강생 학부모 후기
- Bottom CTA 버튼/문구 (고정)

----------------------------------------
치환값 소스
----------------------------------------
- {{지역키워드}}: 폴더명 파싱 (예: 아카데미/경기도/성남시/이매동/고등 수학학원 → 이매동)
- {{메인키워드}}: 폴더명 파싱 (예: 고등 수학학원)
- {{meta}} 및 section1~8 전체: result.html (JSON)
- {{rv_0~5}}: 리뷰 txt 파일에서 random.sample 6개

----------------------------------------
파일 경로 규칙
----------------------------------------
result.html: 아카데미/{시도}/{시군구}/{읍면동}/{메인키워드}/result.html
리뷰 txt:    아카데미/리뷰/{N}/{M}.txt
출력 html:   아카데미/{시도}/{시군구}/{읍면동}/{메인키워드}/index.html
